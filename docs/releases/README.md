# Releases

Este diretório segue UBU-ISO/2.0 e registra o fluxo:

```text
patch > release > nightly > stable
```

## Arquivos

- `PATCH_NOTES.md`: mudanças por patch/release incremental.
- `RELEASE_NOTES.md`: releases consolidadas.
- `NIGHTLY_NOTES.md`: promoções nightly.
- `STABLE_NOTES.md`: promoções stable.

## Regra

Patch sem patch notes é incompleto. Release sem release notes é incompleta.
